# Lumen CA Template

A modern, airy web template tailored for Chartered Accountants, corporate compliance advisors, and tax practices.

## Features
- Fresh teal and coral visual palette
- Floating pill navigation bar
- Bento-grid practice areas & advisory desks
- Filterable statutory tax due dates calendar
- Interactive tax & financial calculators
- ICAI compliance standards & practice credentials about section
- Lead callback consultation forms
